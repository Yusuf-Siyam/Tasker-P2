# Tasker

A simple task management application built with **React** and **Vite**. It allows users to manage daily tasks through a clean and responsive user interface.

## 🚀 Features

- Add new tasks
- Delete tasks
- Search tasks
- Task priority support
- Task tags
- Responsive UI

## 🛠️ Tech Stack

- React
- Vite
- JavaScript (ES6+)
- CSS
- React Icons

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/your-username/tasker.git
```

Go to the project folder:

```bash
cd tasker
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open your browser and visit:

```
http://localhost:5173
```
